# Privacy Policy for Tab Organizer

**Last Updated: July 6, 2026**

## Overview

Tab Organizer ("the Extension") is committed to protecting your privacy. This privacy policy explains how we handle your data.

## Data Collection

### Local Data (stored on your device only)

- **Tab URLs**: The web addresses of tabs you save to workspaces
- **Tab Titles**: The page titles of saved tabs
- **Workspace Names**: Custom names you assign to your workspaces
- **Settings**: Your preferences (e.g., switch mode)

### Anonymous Usage Analytics

To improve the Extension, we collect **anonymous, non-personal** usage data via Mixpanel:

- Feature usage frequency (e.g., how often workspaces are switched)
- Extension version and browser language
- Operating system type
- A randomly generated anonymous identifier (not linked to your identity)

**We do NOT collect:**
- Browsing history, URLs, or tab titles
- Workspace names or their content
- IP addresses (disabled at the analytics platform level)
- Any personally identifiable information (PII)

## Data Storage

- **Workspace data**: Stored locally using Chrome's `chrome.storage.local` API — never leaves your device
- **Analytics data**: Sent to Mixpanel's servers (encrypted in transit via HTTPS) for aggregated analysis only

## Data Usage

- Local data: Used solely to save/restore workspaces and remember settings
- Analytics data: Used solely to understand feature usage patterns and improve the Extension

## Data Deletion and Opt-Out

- **Local data**: Delete individual workspaces in the popup, or uninstall the Extension to remove all data
- **Analytics data**: Uninstalling the Extension stops all data collection immediately. To delete previously collected anonymous data, contact us

## Permissions

- **`tabs`**: To read tab URLs and titles for saving workspaces
- **`storage`**: To store workspace data locally on your device
- **`contextMenus`**: To add right-click menu options for moving tabs
- **`host_permissions` (api-js.mixpanel.com)**: To send anonymous usage analytics

## Third-Party Services

The Extension uses **Mixpanel** for anonymous usage analytics only. Mixpanel's privacy policy: https://mixpanel.com/legal/privacy-policy/

No other third-party services are used. No data is sold or shared for advertising purposes.

## Changes to This Policy

We may update this privacy policy from time to time. Changes will be posted on this page with an updated "Last Updated" date.

## Contact

If you have questions about this privacy policy, please open an issue on our GitHub repository or contact us at cchhll0210@gmail.com.

# プライバシーポリシー - Tab Organizer

**最終更新日：2026年7月6日**

## 概要

Tab Organizer（「本拡張機能」）は、お客様のプライバシーの保護に努めています。本プライバシーポリシーでは、データの取り扱いについて説明します。

## データ収集

### ローカルデータ（お使いのデバイスにのみ保存）

- **タブURL**：ワークスペースに保存したウェブページのアドレス
- **タブタイトル**：保存したタブのページタイトル
- **ワークスペース名**：ワークスペースに付けたカスタム名称
- **設定**：お客様の設定（切り替えモードなど）

### 匿名利用分析

拡張機能の改善のため、Mixpanelを通じて**匿名かつ個人を特定しない**利用データを収集しています：

- 機能の使用頻度（ワークスペースの切り替え回数など）
- 拡張機能のバージョンとブラウザの言語
- オペレーティングシステムの種類
- ランダムに生成された匿名識別子（お客様の身元に紐づけられません）

**収集しないもの：**
- 閲覧履歴、URL、またはタブタイトル
- ワークスペース名やその内容
- IPアドレス（分析プラットフォーム側で無効化済み）
- 個人を特定できる情報（PII）

## データの保存

- **ワークスペースデータ**：Chromeの `chrome.storage.local` APIを使用してローカルに保存——デバイスの外に出ることはありません
- **分析データ**：HTTPS暗号化でMixpanelのサーバーに送信され、集計分析のみに使用されます

## データの使用

- ローカルデータ：ワークスペースの保存・復元と設定の記憶のみに使用
- 分析データ：機能の使用パターンの把握と拡張機能の改善のみに使用

## データの削除とオプトアウト

- **ローカルデータ**：ポップアップでワークスペースを削除するか、拡張機能をアンインストールしてすべてのデータを削除
- **分析データ**：拡張機能をアンインストールすると、すべてのデータ収集が即座に停止されます。収集済みの匿名データの削除をご希望の場合はお問い合わせください

## 権限について

- **`tabs`**：ワークスペース保存のためにタブのURLとタイトルを読み取り
- **`storage`**：デバイス上にワークスペースデータをローカル保存
- **`contextMenus`**：タブ移動のための右クリックメニューオプションを追加
- **`host_permissions` (api-js.mixpanel.com)**：匿名利用分析データの送信

## サードパーティサービス

本拡張機能は匿名利用分析のために **Mixpanel** を使用しています。Mixpanelのプライバシーポリシー：https://mixpanel.com/legal/privacy-policy/

その他のサードパーティサービスは使用していません。データの販売や広告目的での共有は行いません。

## ポリシーの変更

本プライバシーポリシーは随時更新される場合があります。変更はこのページに掲載され、「最終更新日」が更新されます。

# 개인정보 처리방침 - Tab Organizer

**최종 업데이트: 2026년 7월 6일**

## 개요

Tab Organizer("본 확장 프로그램")는 사용자의 개인정보 보호에 최선을 다하고 있습니다. 본 개인정보 처리방침은 데이터 처리 방식에 대해 설명합니다.

## 데이터 수집

### 로컬 데이터 (사용자의 기기에만 저장)

- **탭 URL**: 워크스페이스에 저장한 웹페이지 주소
- **탭 제목**: 저장된 탭의 페이지 제목
- **워크스페이스 이름**: 워크스페이스에 지정한 사용자 정의 이름
- **설정**: 사용자 환경설정 (예: 전환 모드)

### 익명 사용 분석

확장 프로그램 개선을 위해 Mixpanel을 통해 **익명의 비개인** 사용 데이터를 수집합니다:

- 기능 사용 빈도 (예: 워크스페이스 전환 횟수)
- 확장 프로그램 버전 및 브라우저 언어
- 운영체제 종류
- 무작위로 생성된 익명 식별자 (사용자 신원과 연결되지 않음)

**수집하지 않는 정보:**
- 브라우징 기록, URL 또는 탭 제목
- 워크스페이스 이름이나 내용
- IP 주소 (분석 플랫폼 단에서 비활성화됨)
- 개인 식별 정보 (PII)

## 데이터 저장

- **워크스페이스 데이터**: Chrome의 `chrome.storage.local` API를 사용하여 로컬에 저장 — 기기 밖으로 전송되지 않습니다
- **분석 데이터**: HTTPS 암호화를 통해 Mixpanel 서버로 전송되며, 집계 분석에만 사용됩니다

## 데이터 사용

- 로컬 데이터: 워크스페이스 저장/복원 및 설정 기억에만 사용
- 분석 데이터: 기능 사용 패턴 파악 및 확장 프로그램 개선에만 사용

## 데이터 삭제 및 수집 중단

- **로컬 데이터**: 팝업에서 워크스페이스를 삭제하거나, 확장 프로그램을 제거하여 모든 데이터 삭제
- **분석 데이터**: 확장 프로그램을 제거하면 모든 데이터 수집이 즉시 중단됩니다. 이미 수집된 익명 데이터의 삭제를 원하시면 문의해 주세요

## 권한 설명

- **`tabs`**: 워크스페이스 저장을 위해 탭 URL 및 제목 읽기
- **`storage`**: 기기에 워크스페이스 데이터를 로컬 저장
- **`contextMenus`**: 탭 이동을 위한 우클릭 메뉴 옵션 추가
- **`host_permissions` (api-js.mixpanel.com)**: 익명 사용 분석 데이터 전송

본 확장 프로그램은 익명 사용 분석을 위해 **Mixpanel**을 사용합니다. Mixpanel 개인정보 처리방침: https://mixpanel.com/legal/privacy-policy/

기타 제3자 서비스는 사용하지 않습니다. 데이터를 판매하거나 광고 목적으로 공유하지 않습니다.
