PetDex

Privacy Policy

Last updated: August 7, 2026

This policy applies to PetDex version 1.1.0 and later. PetDex is a lightweight pet discovery and collection game that runs in a supported browser's sidebar.

Summary

PetDex uses limited, anonymous product analytics to understand whether people open the extension, start and complete an exploration, discover pets, view the collection, and return on another day. Analytics is enabled by default and can be disabled at any time in PetDex Settings.

PetDex does not collect names, email addresses, account information, browsing history, visited URLs, website or page content, user input, communications, mouse movements, keyboard activity, or precise interaction trails.

Information Stored Locally

PetDex stores the following information in the extension's local browser storage (chrome.storage.local):

  • Discovered pet identifiers and first-discovery dates
  • Number of completed explorations
  • Daily discovery bonus state
  • Selected interface language
  • Collection milestone state
  • Analytics enabled or disabled preference
  • A randomly generated installation-scoped analytics UUID
  • Local first-open and returning-use lifecycle dates
  • Internal storage schema version

The analytics UUID is generated locally with crypto.randomUUID(). It is not derived from or linked to a name, email address, account, browser account, device identifier, or other personal identity information. Uninstalling PetDex or clearing its extension data removes these locally stored values.

The user's language preference remains in local extension storage. When analytics is enabled, PetDex sends only the current interface language as a coarse product-analysis field. It is not linked to personal identity information and is not used for advertising or user profiling.

Anonymous Product Analytics

When analytics is enabled, PetDex sends the following events to Mixpanel, acting as PetDex's analytics service provider:

  • Extension opened: app version, interface language, and coarse user stage
  • Game started: whether it is the first exploration
  • Game completed: whether it is the first exploration and a coarse duration range
  • Pet discovered: new or duplicate, rarity, whether the daily bonus applied, and a coarse collection-progress range
  • Collection viewed: a coarse collection-progress range
  • Returning use: a coarse range of days since first open

Each event is associated only with the locally generated random analytics UUID. PetDex uses these events for aggregate product analysis and product improvement.

PetDex does not use Mixpanel People Profiles, Autocapture, Session Replay, heatmaps, automatic page-view tracking, or IP-based geolocation enrichment. It does not use analytics for advertising, cross-service tracking, sale of data, eligibility decisions, or profiling a natural person.

Analytics Choice

Anonymous analytics is enabled by default. Users can open PetDex Settings and turn off Anonymous analytics at any time. After it is turned off:

  • PetDex stops sending new analytics events.
  • Events generated while analytics is disabled are not queued or sent later.
  • The Memory Match game, discoveries, collection, language setting, and Daily Discovery continue to work normally.

Turning analytics off does not automatically delete anonymous events that Mixpanel processed before the setting was changed.

Information PetDex Does Not Collect

PetDex does not collect or transmit:

  • Names, email addresses, usernames, account identifiers, or other personal identity information
  • Authentication credentials, financial information, payment information, health information, or precise location
  • Browsing history, visited domains or URLs, website content, page content, cookies, or web requests
  • Form data, user-generated text, user input, or personal communications
  • Mouse coordinates, keystrokes, scrolling activity, or detailed interaction recordings
  • Pet collection records, first-discovery dates, or Daily Discovery state. The current interface language is the only language-related field included in anonymous analytics.

PetDex has no account system, advertising network, payment service, cloud synchronization, or business backend.

Data Sharing and Limited Use

PetDex does not sell or rent data. The only data transmitted to a third party is the limited anonymous product analytics described above, sent to Mixpanel solely to operate aggregate PetDex product analytics and improve PetDex's user-facing experience.

PetDex's use and transfer of data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is not used or transferred for personalized advertising, retargeting, creditworthiness, lending, or purposes unrelated to PetDex's single purpose.

Permissions and Network Access

PetDex requests only:

  • sidePanel, to display the game in the browser sidebar
  • storage, to save local game progress, preferences, and anonymous analytics state
  • Host access to https://api-js.mixpanel.com/*, used only to send the disclosed anonymous analytics events over HTTPS

PetDex does not use content scripts and does not access the pages users visit. All executable code, including the Mixpanel client, is bundled inside the extension package. PetDex does not download or execute remote code.

Retention and Deletion

Local PetDex data remains on the device until the user clears extension data or uninstalls PetDex. Disabling analytics stops future event transmission but retains local game progress and the analytics preference.

Anonymous events already processed by Mixpanel may remain according to the PetDex Mixpanel project's configured retention and deletion settings. They are not automatically removed when the local extension is uninstalled because PetDex has no account linking the installation to a person.

Changes

If PetDex's data practices change, this policy and the applicable extension-store disclosures will be updated before those changes are released.

Contact

Users can contact the publisher through the support channel provided on the applicable PetDex store listing.
