⏳ Wait Condition Test

Use these scenarios to test the "Wait Condition" feature of Smart Clicker.

Test 1: Wait for Element Visible

Click "Show Button" to make the hidden button appear after 5s. Set wait condition to visible.

Test 2: Wait for Element Clickable

Button starts disabled. Click "Enable" to make it clickable after 4s. Set wait condition to clickable.

Test 3: Wait for Text Appear

Click "Load Data" to inject text after 3s. Set wait condition to text, text value: DATA_LOADED.

Test 4: Timeout Test

This button stays hidden forever. Set wait condition timeout to 5s to verify timeout behavior (should fail).

↑ Target is permanently hidden. Expect click to fail after timeout.
